# Ford Retain 🚘

Sistema inteligente de retenção pós-venda desenvolvido para monitoramento de clientes Ford com risco de abandono no pós-venda.

O projeto foi criado com foco em experiência do usuário, analytics, gestão de revisões e visual moderno inspirado em plataformas corporativas premium.

---

# ✨ Funcionalidades

- Dashboard inteligente de retenção
- Classificação de risco dos clientes
- Analytics com insights gerados por IA
- Gestão de clientes e veículos
- Tela de detalhes completa
- Sistema de agendamento de revisões
- Status de contato e recuperação
- Interface responsiva para desktop e mobile
- Navegação moderna com Expo Router

---

# 📊 Módulos do sistema

## Dashboard
- Visão geral dos clientes
- Indicadores de risco
- Clientes prioritários
- Navegação rápida

## Clientes
- Busca de clientes
- Filtros por risco
- Cards responsivos
- Informações completas

## Detalhes
- Histórico do cliente
- Score de abandono
- Timeline de revisão
- Sugestão de ação da IA

## Analytics & IA
- Distribuição de risco
- Insights operacionais
- Média de quilometragem
- Relatórios inteligentes

## Agendamentos
- Registro de revisões
- Status de atendimento
- Informações de concessionária
